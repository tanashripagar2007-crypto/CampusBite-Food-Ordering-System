# 🍔 CampusBite - Food Ordering System

A complete Python Tkinter GUI project for a college campus food ordering system.

## Features

### Student
- Registration and login
- Browse food menu
- Search food
- Add/remove items from cart
- Checkout and bill total
- Order history
- Order status

### Admin
- Admin login
- Dashboard with statistics
- Add/edit/delete food
- Availability management
- View and update orders
- View registered students
- Revenue calculation

## Technology
- Python 3
- Tkinter / ttk
- CSV files
- No external packages required

## Run

Open the project folder in VS Code and run:

```bash
python main.py
```

All records are stored in the `data` folder:
- students.csv
- admins.csv
- menu.csv
- orders.csv

## Project Flow

Home → Student/Admin Login → Dashboard → Menu/Cart/Orders

Admin → Dashboard → Menu Management / Order Management / Student Management

## Notes

This project is intended for educational/college use. CSV is used instead of a database so the project is easy to understand and demonstrate.
